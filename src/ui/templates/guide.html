에이전트(Grafana Alloy) 설치 가이드

모니터링 대상 서버에 Alloy 하나만 설치하면 됩니다. 메트릭·로그를 중앙으로 보내고, 임계 초과 시 자동으로 직전 5분 로그를 수집해 AI가 분석합니다. (NAT·Cloud Function 불필요, 서버 아웃바운드만)

동작 흐름

[대상 서버] Alloy ──상시 push(메트릭+로그)──► 중앙(VictoriaMetrics / VictoriaLogs) │ vmalert(CPU>80% 5분 등) 발화 → Alertmanager │ webhook ▼ 분석 서버 /webhook/alert → 직전 5분 로그 pull → AI 분석 → 이 대시보드 + 이메일
메트릭은 임계 판단용으로만 중앙 저장(Grafana 화면은 선택). 로그는 발화 시점에만 분석에 사용됩니다.

1Alloy 설치

Ubuntu / Debian

sudo apt-get install -y curl unzip
curl -sL -o alloy.zip https://github.com/grafana/alloy/releases/latest/download/alloy-linux-amd64.zip
sudo unzip -o alloy.zip -d /usr/local/bin/ && sudo chmod +x /usr/local/bin/alloy-linux-amd64

Rocky / RHEL 계열

sudo dnf install -y unzip   # curl은 기본 제공(curl-minimal)
curl -sL -o alloy.zip https://github.com/grafana/alloy/releases/latest/download/alloy-linux-amd64.zip
sudo unzip -o alloy.zip -d /usr/local/bin/ && sudo chmod +x /usr/local/bin/alloy-linux-amd64

Windows

https://github.com/grafana/alloy/releases/latest → alloy-windows-amd64.exe.zip 다운로드 후 압축 해제

2config.alloy 작성

아래에서 SERVER_NAME(이 서버 식별자)과 중앙 주소만 채우세요. 이 이름이 대시보드 사이트명·알람 호스트와 동일해야 합니다.

// ── 메트릭 ──
prometheus.exporter.unix "n" { }                 // Windows: prometheus.exporter.windows
prometheus.scrape "n" {
  targets = prometheus.exporter.unix.n.targets
  forward_to = [prometheus.relabel.h.receiver]
  scrape_interval = "15s"
}
prometheus.relabel "h" {
  forward_to = [prometheus.remote_write.c.receiver]
  rule { target_label = "host"  replacement = "SERVER_NAME" }
}
prometheus.remote_write "c" {
  endpoint { url = "http://<중앙IP>:8428/api/v1/write" }
}

// ── 로그 (journald + /var/log, 또는 앱 로그 파일) ──
local.file_match "f" { path_targets = [{ "__path__" = "/var/log/**/*.log" }] }
loki.source.file "f" { targets = local.file_match.f.targets  forward_to = [loki.process.h.receiver] }
loki.process "h" {
  forward_to = [loki.write.c.receiver]
  stage.static_labels { values = { host = "SERVER_NAME", job = "syslog" } }
}
loki.write "c" {
  endpoint { url = "http://<중앙IP>:9428/insert/loki/api/v1/push" }
}
로그는 앱 경로를 일일이 받지 않습니다 — journald + /var/log(리눅스) / 이벤트로그(윈도우)만 잡으면 됩니다. 비표준 경로 앱만 path 추가.

3실행

alloy-linux-amd64 run config.alloy --storage.path /var/lib/alloy
# (운영: systemd 서비스로 등록 권장)

중앙 방화벽(ACG)

중앙의 8428(메트릭)·9428(로그)에 이 서버 IP만 인바운드 허용. (VictoriaMetrics/Logs는 무인증 → 공인 전체 노출 금지)

확인

  • 설치 후 몇 분 내 메트릭/로그가 중앙에 쌓입니다.
  • CPU 80% 5분 초과 등 임계 발생 시 자동으로 이 대시보드에 장애가 등록되고 AI 분석·이메일이 발송됩니다.
  • 사이트별 수신자·임계는 사이트 관리에서 설정합니다.
