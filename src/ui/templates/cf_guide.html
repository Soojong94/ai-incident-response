1

2

{
  "access_key": "<NCP IAM Access Key>",
  "secret_key": "<NCP IAM Secret Key>"
}
3
cf_obs_to_webhook 액션 코드에 아래 두 번째 코드 박스 붙여넣기 → Object Storage Event 트리거 연결 (버킷 {{ site.obs_bucket or '' }}, Object Created). 디폴트 파라미터는 비움 — OBS 이벤트가 자동 전달.
